# Architecture Decision Records

Material backend decisions are recorded as numbered Markdown files named `NNNN-short-title.md`.

Each record contains status, date, owners, context, decision, security and privacy impact, alternatives, consequences, rollout, and rollback. Proposed records require review from affected owners. Accepted records are immutable except for corrections; a later record supersedes a prior decision.

Use `0000-template.md` when proposing a decision.
