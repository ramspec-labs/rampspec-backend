# Maintainers

## Current maintainers

| Area | Maintainer | Responsibilities |
| --- | --- | --- |
| Repository administration | `@Hallab7` | Access, branch settings, releases, and security routing |
| Backend architecture | `@Hallab7` | Service boundaries, data model, workflows, and final review |
| Protocol implementation | Unassigned | SEP source review, rule behavior, and interoperability fixtures |
| Security and privacy | Unassigned | Tenant isolation, runners, secrets, signing, and evidence review |

Until additional maintainers are assigned, repository administration owns final decisions but must not bypass required protocol or security review. A change requiring an unassigned specialist remains pending until a qualified reviewer is appointed.

## Becoming a maintainer

Maintainers are selected from contributors with sustained, technically accurate reviews in the relevant area. Appointments and removals are recorded in pull requests updating this file. Maintainers must recuse themselves from decisions where they have a material conflict of interest.
